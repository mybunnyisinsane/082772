# Unmasking Vergil

Interactive practice for recognizing the ordinary Latin beneath Vergil's poetic language.

## Publish

Upload the contents of this folder to the root of a GitHub repository. The site is a self-contained static page and has no dependencies or build step.

- For GitHub Pages, publish from the repository's main branch and root directory.
- For Netlify, connect the repository and leave the build command blank; use the repository root as the publish directory.

The interface, styling, behavior, and content are separated. The major passage text and close-reading questions live in `passages.js`; the 3–4-line divisions and their chunk-specific questions live in `chunks.js`. The unseen diagnostic selection, *Aeneid* 4.160–197, must remain excluded.
