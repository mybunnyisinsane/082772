# Transformations practice audit

## Changes made

- Replaced mechanically equal 3–4-line divisions with 28 short sense units of 2–6 verse lines.
- Added overlap where a grammatical unit crosses a verse boundary, so students see the words needed to complete the thought.
- Displayed the book line number beside every verse.
- Reorganized each activity into a visible sequence: **Notice → Rebuild → Name the transformation**.
- Corrected transformation choices so the answer and distractors are always distinct.
- Removed or reassigned inherited questions that referred to Latin outside the displayed unit, including the mismatches involving *opera interrupta*, *amantīs/celerīs*, *hospes*, *Hesperia*, and *interpres dīvum*.
- Retained only seen passages. *Aeneid* 4.160–197 remains excluded.

## Validation

- 6 major passages
- 28 sense units
- 95 question instances
- 3–5 questions in every unit
- 2–6 complete verse lines in every unit
