PRINCIPAL PARTS ARENA — SESSION LOG SETUP

1. Upload Principal_Parts_Arena_Session_Log.xlsx to Google Drive and open it with Google Sheets.
2. In the new Google Sheet, choose Extensions > Apps Script.
3. Delete the sample code and paste in the complete contents of Code.gs from this package.
4. Click Deploy > New deployment.
5. Choose Web app.
6. Set "Execute as" to yourself.
7. Set access to anyone who can reach the web app. The Sheet itself should remain private.
8. Authorize the script and copy the Web app URL ending in /exec.
9. Open config.js and paste that URL between the quotation marks.
10. Upload config.js, index.html, bank.js, Code.gs, and this setup file to the principal-parts folder on GitHub.
11. Hard-refresh the published page and run one test game. Confirm that a row appears on the Session Log tab.

WHAT THE WEBSITE RECORDS
- First name plus last initial
- Challenge code
- Vocabulary range
- Principal-part round
- Game type
- Timestamp
- Website address

It does not record individual answers or scores.

IMPORTANT LIMIT
This is a classroom accountability notice, not verified authentication. A student can still type an inaccurate name. Keep the Google Sheet private to authorized school staff.
